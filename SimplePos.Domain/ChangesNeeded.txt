# Adding Category, PaymentMethod, and SalePayment to SimplePos

This plan details the design and implementation steps for introducing **Category**, **PaymentMethod**, and **SalePayment** entities into the domain layer (`SimplePos.Domain`).

---

## User Review Required

> [!NOTE]
> **Design Choice: Dynamic PaymentMethod Entity vs Enum**
> In a POS system, payment methods (Cash, Visa, MasterCard, custom vouchers/wallets) can vary by company/tenant and may change over time. We propose modeling `PaymentMethod` as a dynamic domain entity scoped to a `CompanyId`, rather than a hardcoded C# enum. This provides maximum flexibility and aligns with multi-tenant designs.
>
> **Sale to SalePayment Relationship**
> To support scenarios like split payments (e.g., paying part in Cash, part on Card), a `Sale` will have a one-to-many relationship with `SalePayment` instead of storing a single string `PaymentMethod` on the `Sale` entity itself.

### 1. Categories Component

We will create a brand new `Categories` domain folder and define a company-scoped `Category` entity, then link it to `Product`.

#### [NEW] [Category.cs](file:///Users/cheong/Projects/SimplePos/SimplePos.Domain/Categories/Category.cs)
Define the `Category` class, including properties for name, company scope, and active/deleted flags, with rich domain validation.

```csharp
using SimplePos.Domain.Common;

namespace SimplePos.Domain.Categories
{
    public class Category
    {
        public Guid CategoryId { get; private set; }
        public Guid CompanyId { get; private set; }
        public string Name { get; private set; }
        public bool IsActive { get; private set; }
        public bool SoftDeleted { get; private set; }

        private Category() { }

        private Category(Guid companyId, string name)
        {
            CategoryId = Guid.CreateVersion7();
            CompanyId = companyId;
            Name = name;
            IsActive = true;
            SoftDeleted = false;
        }

        public static Category Create(Guid companyId, string name)
        {
            if (companyId == Guid.Empty)
            {
                throw new DomainException("Company ID cannot be empty.");
            }

            if (string.IsNullOrWhiteSpace(name))
            {
                throw new DomainException("Category name cannot be empty.");
            }

            return new Category(companyId, name);
        }

        public void UpdateCategoryInfo(string newName)
        {
            EnsureNotSoftDeleted();

            if (string.IsNullOrWhiteSpace(newName))
            {
                throw new DomainException("Category name cannot be empty.");
            }

            Name = newName;
        }

        public void UpdateToActiveStatus()
        {
            EnsureNotSoftDeleted();

            if (IsActive)
            {
                throw new DomainException("Category is already active.");
            }

            IsActive = true;
        }

        public void UpdateToNotActiveStatus()
        {
            EnsureNotSoftDeleted();

            if (!IsActive)
            {
                throw new DomainException("Category is already inactive.");
            }

            IsActive = false;
        }

        public void SoftDelete()
        {
            EnsureNotSoftDeleted();

            SoftDeleted = true;
            IsActive = false;
        }

        private void EnsureNotSoftDeleted()
        {
            if (SoftDeleted)
            {
                throw new DomainException("Operation cannot be performed on a soft deleted category.");
            }
        }
    }
}
```

#### [NEW] [SalePayment.cs](file:///Users/cheong/Projects/SimplePos/SimplePos.Domain/Sales/SalePayment.cs)
Define the payment ledger entry for a sale.

```csharp
using SimplePos.Domain.Common;

namespace SimplePos.Domain.Sales
{
    public class SalePayment
    {
        public Guid SalePaymentId { get; private set; }
        public Guid SaleId { get; private set; }
        public Guid PaymentMethodId { get; private set; }
        public decimal Amount { get; private set; }
        public DateTime PaymentDate { get; private set; }
        public string? ReferenceNumber { get; private set; }

        private SalePayment() { }

        private SalePayment(Guid saleId, Guid paymentMethodId, decimal amount, string? referenceNumber)
        {
            SalePaymentId = Guid.CreateVersion7();
            SaleId = saleId;
            PaymentMethodId = paymentMethodId;
            Amount = amount;
            PaymentDate = DateTime.UtcNow;
            ReferenceNumber = referenceNumber;
        }

        public static SalePayment Create(Guid saleId, Guid paymentMethodId, decimal amount, string? referenceNumber = null)
        {
            if (saleId == Guid.Empty)
            {
                throw new DomainException("Sale ID cannot be empty.");
            }

            if (paymentMethodId == Guid.Empty)
            {
                throw new DomainException("Payment method ID cannot be empty.");
            }

            if (amount <= 0)
            {
                throw new DomainException("Payment amount must be greater than zero.");
            }

            return new SalePayment(saleId, paymentMethodId, amount, referenceNumber);
        }
    }
}
```
